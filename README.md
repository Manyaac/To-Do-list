📝 To-Do List

A simple and efficient To-Do List application built using HTML, CSS, and JavaScript to help users manage their tasks effectively.

## 🚀 Features
- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📌 Mark tasks as completed
- 🔄 Data persistence 

## 🖥️ Technologies Used
- HTML
- CSS
- JavaScript
